# Buchbucher

Eine simple, elegante Meta-App, die Empfehlungen aus Goodreads und StoryGraph bündelt und sie mit deiner aktuellen Entwicklungsphase abgleicht. Logge dich ein, passe Phase oder Lesetempo an und erhalte einen Feed, der sich mit dir weiterentwickelt.

## Features

- 💫 Login mit kuratierten Demo-Accounts (mira/atlas oder leo/delta)
- 🔁 Meta-Layer: Wir lesen eine kleine Datenbasis aus Goodreads & StoryGraph aus und kuratieren die Schnittmenge
- 🧭 Filter nach "Phase" und Lesetempo, damit dein Feed atmend bleibt
- 🌈 Karten mit Farbstimmungen, Vibes und direktem Link zur Originalquelle

## Entwicklung & Start

```bash
npm install
npm run start
```

Der Server läuft auf `http://localhost:3000` und serviert Frontend & API gleichzeitig.

Zum reinen Syntax-Check der wichtigsten Dateien kannst du `npm run check` nutzen.
